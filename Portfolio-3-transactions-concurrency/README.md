# Portfolio 3: Transactions and Concurrency

This folder contains the practical implementation of transaction management and concurrency control in the Sunrise Hotel Management System using PostgreSQL.

The portfolio demonstrates:

1. Transaction management using COMMIT.
2. Transaction management using ROLLBACK.
3. Transaction isolation and its effect on database operations.
4. Concurrency control using multiple database sessions.
5. READ COMMITTED isolation behaviour and concurrent data changes.

## Files and Evidence

The folder contains SQL scripts, execution screenshots and an explanatory document demonstrating the transaction and concurrency experiments.

PostgreSQL

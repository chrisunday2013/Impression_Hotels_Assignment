# Portfolio 5: Distributed and Cloud Databases

This folder contains the cloud database deployment and distributed database concepts for the Sunrise Hotel Management System.

The portfolio demonstrates:

1. Cloud database deployment using MongoDB Atlas.
2. Remote database connectivity through MongoDB Compass.
3. Creation of guests, bookings, payments and rooms collections.
4. Insertion and verification of cloud database records.
5. The concepts of replication, sharding, availability and consistency.

## Cloud Database

MongoDB Atlas

## Cloud Provider

Amazon Web Services (AWS)

## Region

Cape Town, South Africa

## Case Study

Sunrise Hotel Management System

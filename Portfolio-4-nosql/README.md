# Portfolio 4: NoSQL and Advanced Data Models

This folder contains the practical implementation of NoSQL database concepts using MongoDB for the Sunrise Hotel Management System.

The portfolio demonstrates:

1. Creating and managing MongoDB databases and collections.
2. Performing document queries and filtering records.
3. Updating documents and embedding nested data.
4. Using aggregation pipelines to analyse hotel bookings and payments.
5. Exploring document, key-value, column-family and graph database models.

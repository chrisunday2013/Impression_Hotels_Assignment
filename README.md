# Impression Hotels Assignment
## Advanced Database Systems Practical Portfolio

**Case Study:** Sunrise Hotel Management System  
**Course:** MIT 8103 – Advanced Database Systems  
**Academic Session:** 2026/2027

## Project Overview

This repository presents the practical implementation of database concepts through the Sunrise Hotel Management System. It demonstrates relational database design, query optimisation, transaction management, NoSQL data modelling and cloud database deployment.

## Portfolio Structure

### Portfolio 1: Database Design and Modelling
[Open Portfolio 1](Portfolio-1-database-design/)

Covers the case study, ER diagram, relational schema, primary and foreign keys, constraints and normalisation.

### Portfolio 2: Query Processing and Optimisation
[Open Portfolio 2](Portfolio-2-query-optimisation/)

Demonstrates SQL queries, execution plans, indexing and query performance optimisation.

### Portfolio 3: Transactions and Concurrency
[Open Portfolio 3](Portfolio-3-transactions-concurrency/)

Demonstrates COMMIT, ROLLBACK, transaction isolation and concurrency control using PostgreSQL.

### Portfolio 4: NoSQL and Advanced Data Models
[Open Portfolio 4](Portfolio-4-nosql/)

Demonstrates MongoDB collections, document queries, embedded documents and aggregation pipelines. It also discusses key-value, column-family and graph database models.

### Portfolio 5: Distributed and Cloud Databases
[Open Portfolio 5](Portfolio-5-distributed-cloud/)

Demonstrates cloud database deployment using MongoDB Atlas, remote connectivity through MongoDB Compass and the concepts of replication, sharding, availability and consistency.

## Technologies Used

- PostgreSQL
- pgAdmin 4
- MongoDB
- MongoDB Compass
- MongoDB Atlas
- GitHub

## Learning Outcomes

The project demonstrates practical understanding of relational and NoSQL databases, database performance, transaction management, concurrency control and cloud database technologies.
